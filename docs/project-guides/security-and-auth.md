# Security And Auth

## 当前状态

当前 Node 后端提供浙大学号邮箱验证码注册、密码登录、邮箱找回密码和 Cookie 会话。CC98 注册、登录与绑定接口为历史兼容继续保留，但前端不展示任何入口，也不再把 CC98-only 会话视为可留痕身份。前端只消费后端返回的账号状态，不作为权限边界。

课程内容管理在 Node 后端使用 `admin` 角色和服务端权限检查。新的管理员账号必须满足：数字学号位于 `ADMIN_STUDENT_IDS`，对应 `@zju.edu.cn` 邮箱验证码验证成功，且密码至少 10 位。已有白名单邮箱账号会在服务启动时提升为管理员。管理接口对游客返回 `401`，对普通学生返回 `403`。`ADMIN_CC98_NAMES` 与 `ADMIN_INVITE_TOKEN` 仅为旧后台流程兼容保留。

页面提供开发与演示用途的身份切换器。非游客演示身份拥有相互隔离的浏览器本地数据，
可以体验个人主页、课程、收藏、投稿、评论、通知和演示审核，但不会创建后端会话或获得
服务端权限：

- 游客
- 学号认证学生
- 管理员

权限规则集中在：

```txt
src/services/authService.js
```

## 当前前端能力

- 游客可以浏览、搜索、查看资料和公开个人页，并匿名刷题；这些行为不创建公开或账号持久记录。
- 学号认证学生可以点赞、收藏、评论、投稿、维护资料与课程，并跨设备同步刷题记录。
- 管理员拥有学生能力，并可通过 `#admin` 维护内容、审核投稿和查看操作日志。
- 课程清单、点赞、收藏、评论、投稿、刷题同步和站内消息均由后端按学号认证账号隔离持久化。
- `src/data/config/cc98VerificationCodes.js` 与 `cc98VerificationService.js` 只为旧测试兼容保留；真实页面通过 `authApiClient.js` 调用服务端。
- 邮箱注册和登录只接收纯数字学号，由服务端拼接精确的 `@zju.edu.cn`；别名、完整邮箱字符串和子域均不接受，邮箱绑定后不可更换。
- 旧 CC98 账号仍可通过后端接口绑定邮箱，但只有完成学号邮箱认证后才能使用留痕功能。
- 学生密码最低 8 位，管理员密码最低 10 位；会话默认七天过期，找回密码后旧会话全部失效。

## 禁止误解

- 不要把前端权限判断当作真实认证。
- 不要在组件里写安全决策。
- 不要把验证码、邮箱认证、CC98 认证写成纯前端逻辑。
- 不要在 Vue 组件中硬编码 CC98 mock 验证码。
- 不要把 CC98 前端 mock 验证码文案写成后端已经完成的真实认证。
- 不要让演示账号操作回落到真实写接口；演示状态只能由 `demoAccountService.js` 持久化。
- 不要只在 `#admin` 页面隐藏按钮；所有管理写操作必须继续经过后端角色校验。

## 管理端边界

- 管理员注册密码最低 10 位。
- JSON 写操作要求 `application/json`。
- PDF 上传要求专用请求头、PDF MIME、PDF 文件头和 25 MB 上限。
- 已发布试卷必须保留 PDF；移除文件前需要先下架。
- Netlify 静态托管不提供 SQLite 和上传目录的持久化能力。
- 投稿创建与投稿 PDF 上传要求学号认证会话，且投稿文件只能由原投稿者在待审核状态下更新。
- 点赞要求学号认证，并按账号去重；游客无法通过直接调用接口留下点赞记录。
- 投稿审核和操作日志接口继续执行服务端管理员角色检查。
- 邮箱验证码只用于注册、绑定和找回密码，不用于日常免密登录。
- 邮箱验证码保存为带盐哈希，10 分钟过期、最多尝试 5 次，并执行单邮箱、来源 IP 与全站小时限流。
- 来源 IP 只保存 SHA-256 哈希；管理界面只接收脱敏邮箱。
- SMTP 密钥只允许通过后端环境变量提供，禁止写入仓库、前端、日志或截图。
- 邮箱注册者可以设置唯一昵称；昵称按大小写不敏感检查。账号绑定 CC98 后，昵称必须等于 CC98 名字。
- CC98 绑定和换绑要求当前密码与未使用的验证码，成功后释放旧 CC98 身份并注销其他登录会话。
- 头像上传只接受 JPG、PNG、WebP，最大 2 MB；后端解码后统一输出 512×512 WebP，不信任扩展名或客户端 MIME。
- 公开个人主页只返回公开 ID、昵称、头像和已发布帖子，不返回邮箱、内部用户 ID、投稿状态或审核备注。
- 课表上传仅接受带专用请求头的 XLSX，限制 5 MB，不保存原始文件；解析预览不会修改课程清单。
- 评论写入要求已认证登录账号和同源 JSON，限制 1000 字、重复发送和每分钟发布频率，删除使用软删除。
- 账号课程、收藏、通知及刷题同步接口只向学号认证学生和管理员开放。通知不会因点赞或收藏产生，也不会发送邮件。

## 邮件服务边界

当前只使用 SMTP 发信，不需要 POP3 或 IMAP。浙大邮箱默认配置为 `smtp.zju.edu.cn:994` 且启用 TLS。个人邮箱适合当前低注册量阶段，但应关注学校发信频率限制、客户端专用密码失效和垃圾邮件投递；发送失败时接口返回可重试错误，且不会保留未发出的验证码记录。

生产部署的 Apache 与 Supervisor 模板见 `deploy/`；仍需在实际上线时补充密钥、备份、告警、轮换和公网网关验证。

邮件环境变量与启动方式见 `server/README.md` 和 `.env.example`。
