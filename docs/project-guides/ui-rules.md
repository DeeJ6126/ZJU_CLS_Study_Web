# UI Rules

## 总体气质

界面面向生命科学学院学生，目标是学习和资源查找，不是营销页。采用 Minimal 专业风格：中性底色、青蓝强调、清晰层级和克制的装饰。具体令牌和排版见 `docs/design-system.md`。

## 布局

- 左侧导航 + 右侧内容是主结构。
- 大屏不要写死固定列数，优先使用 `auto-fit` / `minmax`。
- 卡片用于重复项目、弹窗和工具区域；不要把页面区块层层套卡片。
- 控件和卡片默认 4px 圆角，不使用胶囊标签；原有动画 `ThemeSwitch` 保持不变。
- 首页围绕分类搜索、我的课程、上次刷题和近期活动；学子主页目录不在首页展示，后台和管理员能力保留。

## 主题

- 公共页面、账号、管理员、刷题和内容阅读共用深浅主题令牌，不保留页面专属装饰配色。
- 浅色使用中性灰白表面和青蓝主色；深色使用中性深灰表面和较亮青蓝主色。状态色与主色分离。
- 历史主题 ID 保持兼容，但 `minimal-white`、`plant-green`、`life-blue` 统一为浅色，`dark`、`silent-black`、`tech-innovation` 统一为深色，不再维护五套独立配色。

主题数据在：

```txt
src/data/config/themes.js
```

主题 CSS 在：

```txt
src/styles/base.css
```

新增或修改主题后运行：

```bash
npm.cmd run check:themes
```

## 文案

- 面向用户，不展示“来自 CSV”“后端待接入”等实现说明。
- 尽量使用中文。
- 不在 UI 里解释技术结构。
- 投稿入口按钮保持短文案：“投稿”。

## 字体与内容

- 正文和标题使用本地 `Outfit` 与中文字体回退；标识使用本地 `Space Grotesk`，代码使用 `--font-mono`。不添加外部字体请求。
- 统一文章、评论、通知正文、管理员预览、关于正文和刷题答案的默认排版，维护 `src/styles/content-typography.css`，不要在各页面重复定义阅读规则。
- 保留作者显式 UBB 颜色、字号与对齐，只有黑色、白色文字映射到主题正文色。不要用全局强制样式抹去作者格式。
- 活动与关于页面也使用共享规则，不另建视觉主题；样式调整不改变内容安全渲染和权限逻辑。

## 避免 AI 味

- 不使用泛泛的装饰性渐变球。
- 不使用空洞宣传语。
- 不做巨大 hero 落地页。
- 不为历史主题 ID 恢复各自独立的装饰配色。
- 优先让信息密度、课程分类和操作路径真实可用。
