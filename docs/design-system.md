# 生科智学初版设计系统

## 方向

- 产品定位：生命科学学院学子学习平台，优先服务学习资源聚合、学业支持和活动展示。
- 视觉关键词：简洁、学术、生命科学、可信、可持续扩展。
- 和参考页面的关系：保留“左侧固定目录 + 右侧内容区”的导航效率，不沿用其重型 Bootstrap 卡片、英文数据库气质和密集图标墙。

## 视觉规则

- 主色使用深叶绿和实验室浅绿，辅以暖橙作为活动与征集类信息的强调色。
- 侧边栏使用深色学术导航，右侧保持浅色、留白和低密度内容容器。
- 导航图形以编号和抽象双螺旋标识为主，避免临时图片和装饰性图标堆叠。
- 圆角保持克制，卡片半径不超过 8px，贴合后续信息平台的工作型界面。

## 文件架构

- `src/data/`：栏目、链接、描述等结构化数据。
- `src/components/`：可复用渲染组件。
- `src/styles/`：按基础、布局、组件、页面分层管理样式。
- `tests/`：导航数据和组件渲染测试。
- `docs/`：设计系统、产品说明和后续需求文档。
