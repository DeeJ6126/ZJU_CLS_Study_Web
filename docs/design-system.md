# 生科智学设计系统

## 方向

- 产品定位：生命科学学院学子学习平台，优先服务学习资源聚合、学业支持和活动展示。
- 视觉方向：Minimal 专业学习平台，简洁、可信、信息优先，不做营销式首页。
- 保留“左侧导航 + 右侧内容区”的导航效率。公共页面、账号与管理员界面、刷题和内容阅读使用同一套视觉规则。

## 视觉规则

- 中性底色配青蓝强调色：浅色使用 `#f5f8f9` 背景、白色表面、`#213139` 正文和 `#14768a` 主色；深色使用 `#171c1e` 背景、`#22292c` 表面、`#f1f5f6` 正文和 `#84cbda` 主色。
- 侧栏与内容区共享表面、边框和文字令牌，不保留独立的深色侧栏或页面专属装饰配色。成功、错误和警告使用各自语义色。
- 页面区块以留白和分隔线组织；卡片只用于课程等重复项目、弹窗或实际工具。默认无阴影，交互反馈以边框和浅色背景为主。
- 控件和卡片使用 4px 圆角，局部细节可更小；不使用胶囊标签。原有动画 `ThemeSwitch` 保持不变，是圆角形态的明确例外。
- 正文与标题使用 `Outfit`，中文依次回退到 `Noto Sans SC`、`Source Han Sans SC`、`Microsoft YaHei`；课程代码等标识使用 `Space Grotesk`，真正的代码使用 `--font-mono`。两种拉丁字体随站点本地打包，不依赖外部字体请求。
- 字距为 0，紧凑区域使用相应的小字号，不把页面大标题比例搬进表单或工具面板。

## 页面与阅读

- 首页直接提供分类搜索、我的课程、上次刷题和近期活动；学子主页目录不再在首页展示，相关后台和管理员能力保留。
- 课程概览保持筛选、目录和课程分组，使用分隔线组织层级，不把整个页面套进卡片。
- 活动与关于页面沿用同一套页面、控件和阅读样式，不单独维护装饰主题。
- 文章、评论、通知正文、管理员 Markdown 预览、关于正文和刷题答案共用 `content-typography.css`：正文 16px、行高 1.8、最大阅读宽度 880px，表格与代码块允许横向滚动。
- 保留作者显式 UBB 颜色、字号与对齐；显式黑色、白色文字映射为主题正文色，避免切换深浅主题后不可读。样式统一不改变原文内容与安全渲染边界。

## 主题

- `base.css` 是颜色、字体和圆角令牌的来源；页面样式消费令牌，不另建固定浅色或深色配色。
- 历史主题 ID 保持兼容：`minimal-white`、`plant-green`、`life-blue` 共享浅色规则，`dark`、`silent-black`、`tech-innovation` 共享深色规则，不再对应五套不同视觉风格。

## 文件架构

- `src/data/`：栏目、链接、描述等结构化数据。
- `src/components/`：可复用渲染组件。
- `src/styles/`：按基础、布局、组件、页面分层管理样式。
- `tests/`：导航数据和组件渲染测试。
- `docs/`：设计系统、产品说明和后续需求文档。
