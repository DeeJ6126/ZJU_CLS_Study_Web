# UI Rules

## 总体气质

界面面向生命科学学院学生，目标是学习和资源查找，不是营销页。风格应简洁、学术、可信、克制，有生命科学气质但避免过度装饰。

## 布局

- 左侧导航 + 右侧内容是主结构。
- 大屏不要写死固定列数，优先使用 `auto-fit` / `minmax`。
- 卡片用于重复项目、弹窗和工具区域；不要把页面区块层层套卡片。
- 卡片圆角保持克制，通常不超过 8px。

## 主题

当前主题：

- 石墨白：默认阅读主题。
- 林冠绿：生命科学自然感。
- 冰原蓝：理性、清澈。
- 星夜黑：低亮度专注。
- 电弧黑：科技感暗色。

主题数据在：

```txt
src/data/config/themes.js
```

主题 CSS 在：

```txt
src/styles/base.css
```

新增或修改主题后运行：

```bash
npm.cmd run harness:themes
```

## 文案

- 面向用户，不展示“来自 CSV”“后端待接入”等实现说明。
- 尽量使用中文。
- 不在 UI 里解释技术结构。
- 投稿入口按钮保持短文案：“投稿”。

## 投稿弹窗

投稿弹窗字段：

- 标题
- 副标题（选填）
- CC98 名字（选填）
- CC98 链接
- 内容
- 图片（选填）
- 复习资料链接

弹窗组件：

```txt
src/components/ContributionBox.vue
```

## 避免 AI 味

- 不使用泛泛的装饰性渐变球。
- 不使用空洞宣传语。
- 不做巨大 hero 落地页。
- 不让所有主题只换一个主色。
- 优先让信息密度、课程分类和操作路径真实可用。
