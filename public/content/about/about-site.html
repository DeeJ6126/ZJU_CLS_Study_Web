生科智学把课程资料、培养方案、练习题库与学院活动收进同一个入口。下面按「站点地图 → 各模块用法 → 身份与权限 → 内容放在哪里」的顺序，说明这个网站的结构和使用方法。

站点地图

顶部导航有六个入口。每个入口都对应一个 # 开头的地址，可以直接收藏、粘贴给同学，或者在浏览器里手动输入。

入口 地址 能做什么
首页 #home 按「课程 / 资料 / 题库 / 活动 / 用户」五种方式搜索，并查看近期活动与热门资料。
概览 #overview 浏览课程总览，或按专业和年级查看培养方案。
刷题 #quiz 进入已迁移的课程题库，按范围练习并复盘错题与生词。
活动 #activities 查看生科院及相关院系的活动目录。
关于 #about 平台介绍（就是当前这一页）。左侧可切换「关于我们」和「关于网站」。
个人 #profile 登录后管理昵称、头像、课程清单、收藏、帖子和评论。

主要模块怎么用

一、找一门课

  1. 在首页搜索框上方选择搜索类型：课程 / 资料 / 题库 / 活动 / 用户。
  2. 输入关键词。课程可以用课程代码、中文名或英文名搜索，支持多个关键词同时匹配。
  3. 在结果里点进课程，就会进入该课程的详情页。

首页在没输入内容时会显示「常用入口」，可以直接跳到刷题或培养方案。

二、看课程资料

课程详情页用四个页签组织内容：课程总览、学习心得、复习资料、历年试卷。页签和具体条目也有各自的地址，例如 #resources/#BIO2110F/#materials，可以直接分享到某一类资料。

登录后可以对资料点赞和收藏，收藏的内容会出现在个人页的「我的收藏」里。

三、看培养方案

进入「概览」后有两种看法：

  • 课程总览：把全部课程按「专业基础课程 / 专业课 / 通识课」分组列出。
  • 培养方案：先选专业，再选年级（目前提供 2024、2025、2026 级），然后按「按培养方案结构」或「按学期」查看。按学期展开时，每学年分为秋冬、春夏和短学期三段。

培养方案区块右上角有「查看培养方案原文」链接，可以直接对照教务发布的原文。

四、刷题

  1. 进入「刷题」，在「支持课程」里选择一门课程。
  2. 按课程提供的范围选择方式（章节、题型或切片分类）设定本次练习范围。
  3. 作答后提交，由服务器判分；答案按提交、查看或自评逐步解锁。
  4. 做错的题会进入错题本；带生词本的课程还可以把专业词汇收进去。

目前开放的题库是微生物学、植物学和分子生物学，其中微生物学和分子生物学提供生词本。未登录也可以练习，但记录只保存在当前浏览器；完成学号邮箱验证后，进度和错题会同步到账号。

五、看活动

「活动」页按类别展示已发布的活动，顶部可以按分类快速跳转。点击活动卡片进入详情页查看完整介绍。首页的「近期活动」读的是同一批数据。

六、个人主页与站内消息

登录后点右上角头像进入「个人」。可以维护昵称、年级和头像，导入课表生成课程清单，管理收藏、已发布内容和投稿记录，也能编辑或删除自己发过的评论。

投稿被审核、内容被评论或被回复时，会产生站内消息，在右上角账号面板里可以看到未读数。

三种身份能做什么

平台只有三种身份，没有更多角色划分。

身份 可以做什么
游客 浏览全部公开内容、搜索、查看活动、直接刷题。不能点赞、评论、收藏或投稿。
已认证同学 在游客的基础上，可以使用所有需要署名或长期保存的功能：点赞、收藏、评论、投稿、私人课程清单、刷题记录同步。
管理员 在已认证同学的基础上，进入 #admin 维护课程内容、审核投稿、管理活动和查看操作日志。

认证使用浙大学号邮箱：输入学号，平台向对应的 学号@zju.edu.cn 邮箱发送验证码。平台只发送验证码，不会读取邮箱内容。

内容放在哪里

为了让资料好找也好维护，网站把内容分成两类存放：

  • 静态内容：课程目录、课件讲义、复习笔记、历年试卷、题库源文件、活动图片等。它们跟着网站一起发布，访问速度快，但不会因为个人操作而变化。
  • 账号与互动数据：账号信息、已发布内容、评论、点赞、收藏、投稿、活动排期、刷题进度和错题。这些会随使用不断变化，由服务器统一保存，换设备登录也能恢复。

写资料时请让长正文留在内容文件里，不要塞进页面代码，这样改文案不需要改程序，也方便后续维护。

推荐的上手路径

  1. 先到「概览」看一眼自己专业的培养方案，了解要修哪些课。
  2. 再回「首页」按课程代码搜索，进入课程详情页收藏有用的资料。
  3. 有对应题库的课程，去「刷题」按范围练一轮，把错题和生词攒起来。
  4. 完成学号邮箱认证，让课程清单、收藏和刷题记录跟着账号走。
  5. 发现资料缺失或错误，用课程页面的投稿入口提交补充或更正。
