# Site Fonts

Outfit and Space Grotesk Latin variable WOFF2 files come from the `@fontsource-variable/outfit` and `@fontsource-variable/space-grotesk` 5.3.0 npm packages. Their SIL Open Font License notices are retained alongside the files. Vite bundles the assets with hashed names; the site does not request Google Fonts.

Chinese glyphs use locally available Noto Sans SC / Source Han Sans SC / Microsoft YaHei. Headings and body share Outfit; course identifiers and code surfaces use Space Grotesk with Consolas/monospace fallback. Font loading uses `swap`.
