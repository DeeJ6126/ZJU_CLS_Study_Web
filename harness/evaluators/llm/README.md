# LLM Evaluators

LLM evaluation is intentionally not wired to an API yet.

Use this layer later when the project adds AI-generated or AI-reviewed content, such as:

- Course summary generation.
- Submission moderation.
- Study note summarization.
- UI copy review.

Suggested rubric:

- Is the output accurate to the source material?
- Is it written for life-science students?
- Does it avoid generic marketing language?
- Does it preserve course codes and source references?
- Does it avoid inventing unavailable resources?
